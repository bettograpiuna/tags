Mini Site Institucional - Seu Café!

Este projeto é um mini site institucional para uma cafeteria fictícia chamada "Café Aconchego". Foi desenvolvido como parte de um exercício prático para aplicar conceitos fundamentais de HTML5, com foco em semântica e estruturação de páginas web.

☕ Sobre o Projeto

O objetivo foi criar um site simples, porém funcional, com três páginas principais:

    Página Inicial (index.html): Apresenta o café, com uma mensagem de boas-vindas e um vídeo incorporado para criar um ambiente agradável.

    Página Sobre (sobre.html): Conta a história e a missão da cafeteria.

    Página de Contato (contato.html): Oferece um formulário simples para que os clientes possam enviar mensagens.

✨ Funcionalidades Principais

    Navegação Clara: Um menu de navegação presente em todas as páginas, permitindo que o usuário transite facilmente entre as seções.

    Estrutura Semântica: Utilização correta das tags semânticas do HTML5 (<header>, <nav>, <main>, <footer>), melhorando a acessibilidade e o SEO.

    Mídia Incorporada: Inclusão de um vídeo do YouTube através de um <iframe> na página inicial.

    Formulário de Contato: Um formulário funcional para coleta de nome, e-mail e mensagem do usuário.

🚀 Tecnologias Utilizadas

    HTML5: Para a estruturação e conteúdo do site.

    Git & GitHub: Para versionamento do código e hospedagem do repositório.

Futuramente, o projeto poderá ser estilizado com CSS3 para melhorar a aparência e a experiência do usuário.

🛠️ Como Executar o Projeto

Como este é um projeto front-end estático, não há necessidade de instalação de dependências. Basta seguir os passos abaixo:

    Clone o repositório:
    Bash

git clone https://github.com/[seu-usuario]/[nome-do-repositorio].git

Navegue até a pasta do projeto:
Bash

    cd [nome-do-repositorio]

    Abra o arquivo index.html no seu navegador de preferência.

        Você pode simplesmente dar um duplo clique no arquivo.

🎯 Objetivo do Aprendizado

O desenvolvimento deste mini site teve como foco principal a prática dos seguintes conceitos:

    Criação da estrutura base de um documento HTML.

    Uso de tags semânticas para organizar o conteúdo de forma lógica.

    Criação de links para navegação entre páginas locais.

    Incorporação de conteúdo externo com <iframe>.

    Construção de formulários simples para interação com o usuário.
